# AYA Assets

Pacotes de modelos 3D **grátis (CC0)** usados pela **Biblioteca AYA** do AYA Studio (AYA GAME STUDIO).

O AYA Studio lê o `catalogo.json` deste repositório e baixa cada modelo só quando ele é usado
(depois fica guardado no PC e funciona sem internet). Assim dá para adicionar pacotes novos
sem gerar o programa de novo.

## Pastas

| Pasta | Conteúdo | Licença |
|---|---|---|
| `quaternius/` | Personagens, animais, monstros e natureza low-poly (Quaternius) | CC0 1.0 |
| `kenney/` | Kits da Kenney (natureza, castelo, cidade, espaço, móveis...) | CC0 1.0 |
| `thumbs/` | Miniaturas para a Biblioteca | CC0 1.0 |

## Regras

- **Só CC0** (domínio público, uso comercial livre, sem obrigação de crédito).
  Nada de GPL, CC-BY-SA ou "só uso pessoal".
- Formato `.glb` (um arquivo por modelo, texturas embutidas), leve o bastante para celular.
- Cada item novo entra no `catalogo.json` com nome em português, categoria, tags, autor, licença e origem.

## Créditos (não obrigatórios, mas merecidos)

- Quaternius — https://quaternius.com
- Kenney — https://kenney.nl
